# AccessiUX Market branding

These assets are intentionally versioned so every fresh clone or deployment uses the same AccessiUX Market identity.

- `accessiux-market-logo.png`: official full AccessiUX Market logo used by the application header and footer.
- `accessiux-market-isotype.png`: official compact isotype for brand surfaces that need a square mark.
- `accessiux-mark.svg`: vector fallback/canonical compact mark used by accessible documents and print-safe UI surfaces.
- `../favicon.ico`: official browser/tab icon.
- `../favicon.svg`: vector fallback retained for compatibility and document use.

Do not rely on untracked local files under `public/branding` for production branding. Any official asset used by the application must be committed to the repository.
